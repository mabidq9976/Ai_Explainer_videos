# GEO checklist

1. The direct answer sits in the first two sentences, before any background.
2. Each H2 is a question a person would actually ask (or type into an AI).
3. Each section opens with a one-sentence answer, then detail.
4. Every factual claim links to its source.
5. At least one original element: the author's opinion, a test they ran, or a small dataset — labelled as such.
6. Named entities are explicit (tools, companies, standards spelled out once in full).
7. Lists and tables for anything comparable or sequential.
8. An FAQ block closes the post (3–5 Q&As, each answer ≤ 60 words).
9. Title ≤ 60 chars and meta description ≤ 155 chars, both containing the core question's key phrase.
