# Hooks library

Patterns the hook-writer must rotate through. `/retro` promotes proven winners into the bottom table.

| Pattern | Shape | Example |
|---|---|---|
| bold-claim | Flat statement that contradicts what they believe | "Ranking first on Google no longer means you get cited." |
| myth-bust | Name the myth, then break it | "More keywords won't get you into ChatGPT's answers." |
| number | Specific number + payoff | "Three lines of schema got this page cited by Perplexity." |
| question | A question the viewer has actually asked | "Why does ChatGPT quote your competitor and not you?" |
| before-after | Contrast two states | "Last month: page one. This month: the AI answer." |
| warning | Cost of not knowing | "If your page hides the answer, AI will skip it." |

## Niche favourites (SEO / GEO / AIO for builders and marketers)
These shapes consistently work in this niche. Prefer them; every hook-writer run uses at least two.
The examples are **shapes, not facts**: numbers, names and audits must come from the brief's sources.

| Pattern | Shape | Example |
|---|---|---|
| specific-result | A named type of business + a concrete, sourced result | "This plumber got 40 calls a month from one blog post." |
| mistake-callout | Tell the viewer they're making a mistake, then name its cost | "Your website is invisible to Google because of this." |
| contrarian | Pick an enemy or common spend and reject it, offer the alternative | "Stop paying for SEO. Do this instead." |
| live-proof | Do it on camera to a real example (only when the brief has the audit) | "I audited a random bakery's website. It's bad." |
| curiosity-gap | A surprising fact, then promise how to use it | "Reddit is outranking businesses. Here's how to use that." |

## Rules
- 6–14 words, speakable in under 3 seconds.
- Open with the viewer's problem or a surprising fact. Never "In this video".
- No jargon in the first line — explain GEO / AIO later.
